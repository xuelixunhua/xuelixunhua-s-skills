# 写作与成文

阅读导航：[工作流](#自适应写作工作流) · [写作决策说明](#写作决策说明) · [写作方法](#写作能力与方法) · [完成检查](#完成条件与返工入口) · [交付边界](#交付边界)

## 模块定位与双层架构

### 模块职责

接管需要实质成文的文本任务：先确定产物用途与类型，再调动现实取样、立意、材料、构思、结构、表达、修改和排版能力，把主题、材料、判断或草稿加工成适合真实使用者、作者位置与场景的文本。笔记是其中一类复杂产物，由本模块进入并调用专门规则。已有判断的简短转述、局部措辞或确定性核对，按 [模块切换与读取边界](SKILL.md#模块切换与读取边界) 直接完成；需要补机制或重建判断时，先进入分析，再返回受影响内容。

### 外层：自适应写作工作流

A—D 负责推进任务：确定方向与边界，形成足以组织文本的判断，把判断组织成可展开的方案，再完成正文与验证。它们存在能力依赖，但不是只能单向前进的固定流水线；应从输入已经成熟的位置进入，并根据新事实、展开困难、反方和用户反馈返回真正的故障层。

### 内层：写作能力与方法

写作方法围绕主题与观点、材料与论据、构思、提纲、结构形态、逻辑关系和表达展开。下文按使用问题归类；标题顺序不表示执行顺序，各项也不构成彼此排斥的分类。构思贯穿观点形成与内容组织，逻辑关系同时存在于论证、提纲和正文结构中，各种方法可以互相校正，并被 A—D 的不同阶段反复调用。

### 工作流与写作方法的映射

| 工作流阶段 | 当前要解决的问题 | 主要调用的能力 |
| --- | --- | --- |
| **A 定向** | 写什么、为何写、由谁写给谁、以什么载体和边界交付 | 任务与场景约束；必要时调用现实判断与横向思维 |
| **B 明确内容** | 组织中心是什么，材料与证据能够支持到哪里 | 主题、观点与材料；构思；贯穿写作的思维方法 |
| **C 组织** | 怎样把判断变成读者能够走通的结构和表达方案 | 构思与提纲；结构与关系；叙述、说明与议论；贯穿写作的思维方法 |
| **D 成文与验证** | 怎样写出、校正并验证真实成品 | 叙述、说明与议论；结构与关系；思维方法按缺口调用，发现上游故障时返回相应方法和阶段 |

映射描述主要调用关系，而不是排他的所有权。同一能力可以服务多个阶段，同一阶段也可以根据文本类型和输入成熟度选择不同能力组合。

## 完成条件与返工入口

文本必须通过与实际用途有关的质量门。每一项既是成功标准，也是返工路由：

- **任务效力**：目标使用者能够借助文本形成预期认识、决定、行动、记忆或后续调用。说不清文本要完成什么，返回 **A 阶段**重新定向。
- **组织中心**：论证、评论、研究文章以及判断型主笔记、专题笔记，由一个可被支持、反驳和限制的中心判断统摄；解释文本围绕核心问题及其答案，叙事和随笔围绕人物变化、核心张力或体验主线；记录、索引和证据卡则要有清楚的记录对象、颗粒度、字段与来源边界，不为追求“立意”补造观点。组织中心不成立，返回 **B 阶段**。
- **现实与证据**：关键事实可靠，主张、证据、推理和边界闭合。现实接触不足时补取样；材料不足时补证、缩小判断或保留不确定性，不能用通用内容填空。
- **结构成立**：主路径、结构形态和内容关系相互一致；上下、同层、前后和整体检查全部通过。标题整齐却存在错层、重复或断裂，返回 **C 阶段**重构。
- **表达有效**：叙述、说明和议论解决了读者相应的认知困难，段落持续推进认识。功能错配或段落空转，返回 **C 阶段**重新配置表达方式。
- **场景与责任匹配**：文体、作者位置、读者、语气、授权、隐私、归属和行动接口与真实用途一致。位置或文种错误返回 **A 阶段**；事实、责任或边界缺失返回 **B 或 C 阶段**。
- **作者判断与中文成立**：面向读者的连续正文通过材料取舍、关系解释和边界体现真实作者，中文自然，没有明显模板腔、翻译腔、机械完整或伪经历；此类完整成稿必须在 **D 阶段**执行 [反 AI 味审阅](references/anti-ai-smell.md)。
- **Markdown 清楚美观**：视觉层级准确呈现语义层级，版面简洁、稳定、易读。Markdown 成稿必须在 **D 阶段**执行 [Markdown 排版审阅](references/markdown-layout.md)。

笔记任务在 **A 阶段**完整读取 [笔记处理方法](references/note-processing.md)。其中的笔记类型、输入成熟度、保全强度、来源映射、结构重组和长期调用要求，是笔记产物的附加质量门。原始纪要、记录表、索引和证据卡不强制建立文章式立意、作者声音或反 AI 味，但不能降低事实、归属、完整性和可追溯性。

任何一项未通过，都不能用下游润色掩盖。局部标题、摘要、排版、诊断或改句任务只通过与交付范围有关的质量门；面向读者的完整成稿必须完成最终审阅。

## 自适应写作工作流

### 工作流原则

A—D 是四个可回返阶段，不是要求逐字展示给用户的流水线。它们规定能力依赖、reference 调用和返工位置，同时保留写作判断：

- 从输入已经成熟的位置进入。用户已有可靠立意、材料、提纲或正文时复用，不从 A 阶段重新表演。
- 立意、取材、构思和提纲可以互相校正；正文也可以迫使作者返回上游。新事实、展开困难、反方和用户反馈都属于改道证据。
- 只有缺失信息会改变事实、组织中心、作者声音、读者、产物类型或正式效力时，才询问 1—3 个高信息量问题。
- 用户只要诊断时定位故障和返工入口；只要局部修改时直接进入相应阶段，不擅自扩张交付物。
- 达到全部相关质量门后停止，不追加无任务价值的标题、总结、金句、互动问题或方法论升华。

进入工作流前，快速检查已有输入的可靠程度、当前缺口与用户锁定内容。已有提纲不等于证据成立，已有正文不等于结构成立；按可靠程度选择入口：

| 当前输入与缺口 | 进入方式 |
| --- | --- |
| 用途、读者或关键边界不清 | 在 A 补足会影响行动的缺口；可从上下文确认的事项直接复用 |
| 方向清楚，观点或证据不足 | 进入 B；已有可靠材料和判断继续沿用 |
| 判断与材料可靠，组织方式不清 | 进入 C；已有提纲先检查关系与证据落点 |
| 结构和依据成立，需要成文或局部语言修改 | 进入 D；只处理授权范围内的缺口 |

A 的任务理解贯穿所有入口，成熟输入可以用一次简短核对满足，不必重问全部约束。用户锁定的内容若存在事实或逻辑问题，应指出影响并提出具体修改建议，不能暗中改写。

区分探索推进与正式交付：B、C 的出口要求用于判断当前方案是否成熟，尚未满足时仍可带着明确标记的假设或缺口做局部提纲、结构比较或关键段落试写。

试写属于探索，可以从 B 或 C 调用 D 的成文能力，再将结果反馈回来；探索发现的句式问题也可以局部调整，不以语言打磨代替待解决的判断。最终交付必须达到与用户请求相符的质量标准；若交付的就是探索稿，假设和待验证处应清楚保留。

返工按受影响范围推进：先修具体事实、论据、段落或子论点，再检查依赖它的上下文；只有中心认识或整体结构被动摇时才扩大重构。没有新增证据或具体故障时，不重复整套流程。

执行时先完成当前任务必需的判断和简短阶段结果；遇到具体缺口再调用详细方法。方法库保留完整技法，执行不以逐条用完为目标。说明有实质内容、正文兑现判断、相关质量门通过后停止，不追加方法展示。

写作规则按约束强度使用：

- **硬约束**来自事实、授权、法律、正式程序、格式、公平、自主、隐私、保密和安全，必须遵守。程序与公平不是可以用短期效果交换掉的形式成本。
- **文体规则**来自文本效力和读者预期，默认遵守；调整时要确认不会破坏理解、授权或行动。
- **经验技法**包括特定原型、开头、金句、回环和个人工作习惯，只在改善当前文本时采用，不能反过来支配材料和判断。

### A 阶段：定向与场景约束

先从用户指令、既有材料和上下文核对八个写作约束；已明确的直接沿用，只询问会实质改变结果且无法可靠确定的缺口：

- **文本产物**：记录型笔记、主笔记、知识框架、文章、报告、纪要、公文、方案或其他明确产物；
- **文本动作**：记录、解释、论证、建议、请示、决定、部署、复盘还是传播；
- **核心问题**：这篇文本真正需要回答什么；
- **作者位置**：以个人、专业岗位、部门、会议或组织身份发言；
- **目标读者**：读者已经知道什么，真正关心什么，最可能反对什么，能决定什么，看完后能够做什么；
- **呈现载体**：口头表达、即时消息、邮件、PPT、正式报告、长篇文章、长期笔记或其他界面，以及相应的时间、篇幅和扫描阅读预算；
- **交付范围**：用户要选题判断、立意、提纲、完整成稿、改写、质检、标题还是排版；
- **现实边界**：事实来源、授权、程序、公平、自主、隐私、保密、安全、归属、篇幅、格式和时效要求。

同时确定协作方式与作者特征：用户深度参与时，在关键立意、结构和重大改写处提供具体方案讨论；用户已授权直接成稿时连续推进，只对无法自行解决的重要缺口提问。

已有范文、作者立场、观察方式、语气和保全要求，从选材与构思开始生效；需要恢复作者风格且现有依据不足时，可提前读取 [作者声音与活人感](references/live-voice-techniques.md)，D 再对照成稿复核。没有依据时不推测作者经历与情绪。

先按产物分流：

- 属于笔记、会议记录、书籍课程整理、主笔记或知识框架时，完整读取 [笔记处理方法](references/note-processing.md)，由它确定笔记类型、输入成熟度、保全边界和具体整理方式；
- 属于文章、公众号、随笔、研究技术文本、职场汇报、述职发言、公文或组织文本，且文体会改变必要内容、效力或授权时，读取 [文体与场景写作指南](references/writing-genres-and-scenarios.md) 的场景索引与命中章节；
- 只做标题、局部改写、语言审阅或排版时，不加载与局部交付无关的完整产物规则。

先确定文本必须完成什么、哪些规则是硬约束，再进入内容形成；不要为一个产物加载无关 reference。

出现以下情况，读取 [thinking-analysis.md](thinking-analysis.md) 补问题定义与现实判断：只有宽泛主题或态度；写作目标互相冲突；不知道真正矛盾；结论依赖尚未处理的机制、选择或反方。若缺失的是用户独有经历、立场、事实或授权，向用户询问，不用通用内容代填。

**离开 A 阶段前必须明确**：要形成什么产物，谁以什么位置，为谁，围绕什么问题，完成什么文本动作，通过什么载体交付到什么范围，受哪些事实和权限约束。缺一项且会改变结果，就不能继续假装方向已经成立。

### B 阶段：现实取样、立意与证据

调用下文的 [立意能力](#立意能力) 与 [现实取样、材料和证据能力](#现实取样材料和证据能力)，按当前缺口选择实证、系统、逻辑和多视角思维；不要求每次全部调用：

- 判断现有输入能否支撑写作。若只有抽象主题或二手观点，先回到真实对象、不同位置、工作过程、数据或可靠来源；
- 判断尚未确定或存在实质性分歧时，从材料中提出多个可能判断，再按现实重要性、证据强度、读者增量和作者可信位置进行竞争与淘汰；已有可靠且符合任务的判断时直接检验与沿用；
- 把最终立意压缩成一句可以被支持、反驳和限制的核心认识；
- 为关键主张配置事实与证据，写清证据如何支持判断、能够支持到哪里；
- 主动寻找最强反例、替代解释和成立条件，必要时修改立意。

上述立意竞争用于需要形成判断的论证、评论、研究文章以及判断型主笔记、专题笔记。解释文本可以围绕核心问题及其答案组织，叙事与随笔可以围绕人物变化、核心张力或体验主线组织；其中的事实和判断仍需可靠依据，不强迫每种文本都生成一个可反驳的论点。

记录型笔记、原始纪要、索引和证据卡不强行提炼作者立意；B 阶段改为确认记录对象、来源、归属、时间、口径、缺口与不可改写内容，并按 [笔记处理方法](references/note-processing.md) 确定保全和压缩强度。

因果、概念、取舍或价值标准仍不清楚时，插入 [thinking-analysis.md](thinking-analysis.md)，按其中“与写作模块的交接”带入当前问题、必要材料、锁定内容与原提纲；分析结果必须压回 **核心判断、关键关系、支撑证据和成立边界**，并说明对原提纲或正文的影响；未证实的解释保留为假设，只改受影响内容，过程摘要并入已有写作决策说明。材料缺口只能由现实取样、来源核验、补充研究、用户输入或缩小主张解决。

**B 阶段的成熟条件**：面向读者的判断型文本要有一句核心认识、支撑它的关键证据链、最强反方或替代解释和成立边界；记录型文本要有明确对象、来源映射、保全规则、缺失状态和不可越过的改写边界。

解释与叙事文本应形成足以指导取材的核心问题、变化或主线及相应材料依据。各类产物都必须足以决定材料取舍和结构轻重；未成熟时按工作流原则进行带标记的探索，不能把暂定判断写成定论。

### C 阶段：构思、结构、提纲与表达配置

调用下文的 [构思与展开路径](#构思与展开路径)、[结构形态](#结构形态)、[提纲编制](#提纲编制)、[关系检查](#关系检查) 和 [叙述、说明与议论](#叙述说明与议论)，把 B 阶段的认识变成读者能够走通的路径。

笔记产物还要先服从 [笔记处理方法](references/note-processing.md) 已确定的保全、溯源、知识层级和目标文档结构。

- 找到读者最难跨过的认知障碍，选择一个足够具体、能够展开且具有解释力的切口；
- 选择一条主展开路径，再判断正文采用纵向、横向还是交叉结构；
- 为读者首次看见的同级主入口配置注意力预算。解释、建议和汇报默认收敛为 3—7 个；超过 7 个先聚类、排序或下沉。横向分类还要执行 MECE 检查：各项回答同一问题、彼此不重叠，并在当前任务边界内无重大遗漏；真实结构只有两项时保留两项，只检查是否存在被漏掉的状态、条件或连续谱。
- 给相邻内容标明并列、递进、因果或约束关系，不用连接词替代真实逻辑；标题、层级与编号依真实关系配置，并列内容不因编号而被解释为顺序，真正有阶段依赖时才用顺序表达；
- 按篇幅、复杂度与输入成熟度建立功能型提纲。短文或局部修改可简要明确段落职责和必要关系；复杂长文的详细提纲，每个主要部分至少标明：**承担的功能、子判断、所用材料、主表达方式、与上下文的关系**；
- 对提纲执行上下、同层、前后、整体四项检查，任何一项失败都要实际移动、合并、删除或补充内容；
- 决定哪里需要叙述让过程可见，哪里需要说明讲清对象和机制，哪里需要议论完成判断与取舍。
- 复杂关系需要外化时，先识别真实关系再选择视觉桥：层级用树，时间或因果用时间线与流程，同口径比较用表格，两个有解释力的轴用四象限，反馈关系用循环。SWOT、PDCA、需求层次等现成模型只有在保留真实关系时才使用，不能先选名框架再填内容。
- 职场口头表达、即时消息、PPT、述职和复盘需要短时调用结构时，读取 [文体与场景写作指南](references/writing-genres-and-scenarios.md) 的“职场表达适配器”。每个表达单元只选择一个最合适的适配器；公式负责压缩和排序，不替代事实、证据、推理、边界、贡献归因或授权。

记录表、索引和证据卡可以使用字段、映射或时间结构，不必改造成连续论述；主笔记与专题笔记则要让标题和段落共同呈现知识关系，不能只按来源顺序堆放。

公众号、方法文章、随笔评论、研究技术文章或组织文本需要场景结构时，读取 [文体与场景写作指南](references/writing-genres-and-scenarios.md) 的对应章节。场景原型只帮助配置材料、开头、展开和收束，不能替代共同立意、证据和关系检查。

**C 阶段的成熟条件**：面向读者的判断型文本要有一个有效切口、一条主认知路径、明确的结构形态、通过关系与注意力预算检查的功能型提纲、关键证据落点、载体适配和主要表达方式配置；解释与叙事文本要明确问题或变化如何展开、关键材料放在哪里、读者怎样理解其联系；记录型文本要有可执行的记录结构、字段或映射关系，并确认信息没有因重排失去归属。

若尚未成文就已出现重复、错层或证据无处安放，先修结构。对无法仅靠提纲判断的展开困难，可以试写关键段落，再校正提纲、结构或判断；无需在每次试写前具备完整的详细提纲。

### D 阶段：成文、修改、审阅与排版

#### 写出并校正正文

起草时执行 `SKILL.md` 的高优先级表达约束：新写自然语言不用双引号，不用 `不是……而是……` 及同构变体。该要求同样适用于标题、摘要、图注和过程说明，局部改写也要遵守；机器语法和必须逐字保真的原文按 [反 AI 味审阅](references/anti-ai-smell.md#高优先级表达约束) 保持准确。

面向读者的连续正文按当前成熟度足够的功能型提纲成文；短文可使用简要段落安排。探索性试写遵循工作流原则，保留假设与缺口。每个段落应承担与全文相关的作用：提供事实、建立关系、形成判断、解释机制、限制结论、回应反方、完成转折或推动行动，也可以建立场景、铺垫情绪、调整节奏、转换视角或形成照应。

作用由文体与上下文决定，不要求每段都增加论点。记录表、索引、证据卡和高度格式化笔记按各自记录单元完成来源、归属和调用功能，不强行改成文章段落。写作中出现新事实或关系时，允许立即返回 B 或 C 阶段。

简洁是对读者注意力的配置，不是机械缩短。读者已知且不影响推理的背景可以压缩；少见、关键、容易误解的事实和条件必须展开。每段若既不承担事实、关系、判断、边界或行动功能，也没有有效的场景、情绪、节奏、视角或照应作用，应删除、合并或重写；具体改动仍服从用户的保全边界。

呈现节奏服从载体。即时消息、PPT、口头提词和移动端扫描内容可以做到一意一行、三个及以上同轴对象纵向排列，并把少量关键数字或已证明的结论单独钉住；长篇报告、研究笔记和连续论证保留自然段。减少逗号应通过拆开过多认知动作完成，不把“每个句号都换行”设成跨文体硬规则。

初稿完成后，按影响范围修改：

- **大改**处理事实与任务、核心认识和总体结构；
- **中改**处理模块顺序、证据配置、标题层级和段落功能；
- **小改**处理句子、词语、语气、格式和标点。

修改顺序为：

> **事实与任务 → 核心认识 → 展开路径与结构 → 证据配置 → 段落关系 → 句子与词语 → 格式和标点**

上游问题未解决时，不进入语言美容。提纲无法展开，返回构思或立意；关键句反复写不清，先检查其主张、证据和关系；新证据改变结论，返回 B 阶段。

大改、中改和小改描述影响范围；具体操作同时包含：**减法**删除离题、重复和无效材料，**加法**补事实、推理、反例、条件和行动接口，**换法**改变切口、顺序、证据、比喻或表达角度。精练必须降低理解成本，不能把必要条件一并删掉。

修改自己文本时，时间允许可先冷却再通读；时间紧时用朗读、目标读者、怀疑者、决策者、执行者或未来复核者视角制造距离。不要一发现局部句病就立即动笔，先判断它是否来自更上游的事实、判断或结构故障。

修改别人或多人协作文本时，先锁定用户要求保留的事实、判断、作者位置、语气和边界。重大重构应能说明改变了什么关系，不能用自己的风格覆盖原作者，也不能凭空补造作者经历。

按风险向真正掌握缺口的人取反馈：目标读者检验理解，专业人员检验口径，执行者检验可行性，受影响对象检验成本；最终判断和签发责任仍由有权主体承担。版本对照用于确认修改没有偷换立场，并把有效修改沉淀为下一稿可验证的规则。

诊断草稿时优先追到五类根因：**事实不足、判断越界、结构失控、信息错配、语言遮蔽**。前四类返回 A—C 的对应位置；只有事实、判断与结构已经成立，才把模板句、术语堆积、长句失控和机械节奏交给语言审阅。

成文后调用 [结构与关系](#结构与关系) 检查实际正文，覆盖全文组织、段落承接、表达转换及必要的句内关系；提纲通过不代表正文自动通过。问题按影响范围修复，并纳入成稿复核说明。

#### 执行反 AI 味与作者声音审阅

本节只用于面向读者的连续正文。原始纪要、记录表、索引、证据卡和高度格式化笔记不强制执行。

当内容、证据和总体结构基本稳定后，完整读取 [反 AI 味审阅](references/anti-ai-smell.md)，直接对成稿执行语言审阅和修改：

- 先扫描中文与英文双引号、禁用对照句及其同构变体；新写自然语言中的命中项必须改写，逐字引文与机器语法单独核对，不进行破坏性替换；
- 保留已经确认的事实、核心认识、作者位置与有效结构；
- 修正模板句、翻译腔、均匀节奏、伪口语、伪故事和被语言抹平的作者判断；
- 修改后再次通读。若发现真正问题是判断空心或结构机械，停止语言修补并返回 B 或 C 阶段。

对照 A 阶段确定的作者特征复核成稿。删除明显 AI 痕迹后，若文章仍找不到真实作者、语体与场景不匹配，或用户明确要求恢复个人风格，按需读取 [作者声音与活人感](references/live-voice-techniques.md)。第一人称、口语、幽默和情绪是可选择的表达手段，不是必须使用或一律禁止的风格标记。

#### 执行 Markdown 排版审阅

文字稳定后，完整读取 [Markdown 排版审阅](references/markdown-layout.md)，让标题、段落、列表、加粗、引用、表格、链接、代码和留白准确表达内容关系。排版不能改变事实、立意和文体，也不能用更多格式掩盖结构问题。

#### 最终交付

重新逐项检查完成条件与返工入口，并把实际成品与任务契约、判断与证据账本、提纲契约逐项对照。若正文遗漏预定论据、改变结论强度、打乱必要关系或新增计划外主线，必须判断它是有证据的合理改道还是执行漂移；前者按可见模式说明证据与影响，后者返回对应阶段修复。

面向读者的完整连续成稿只有在反 AI 味审阅和 Markdown 排版审阅都实际完成、所有相关质量门均通过后才能交付；记录型文本通过其保全、归属、结构、溯源与格式要求即可，不为凑齐审阅步骤改写原始信息。默认只给用户请求的成品，Content Trace 只留在 commentary，不把内部阶段、检查表或思维脚手架复制进最终正文。

## 写作决策说明

### 阶段产物与可见边界

以下中间契约用于约束成品，其内容可以保留在当前判断、提纲或正文批注中，不要求分别生成文档。按任务规模展开细节，并服从 `SKILL.md` 的 Content Trace 可见模式和用户当前的过程偏好：

- **任务契约（A）**：产物与文本动作、核心问题、作者和读者位置、载体、交付范围、硬边界；说明从哪个成熟位置进入。
- **判断与证据账本（B）**：判断型文本记录中心认识、关键事实、证据怎样支持主张、最强反方或成立边界；解释与叙事文本记录核心问题、变化或主线及材料依据。记录型文本改为记录对象、来源映射、保全规则、缺失状态和不可改写边界。
- **提纲契约（C）**：主认知路径和结构形态；每个主要部分承担的功能、子判断、证据落点和上下文关系；说明为什么该结构比实质性备选更适合当前任务。
- **一致性报告（D）**：正文是否仍执行任务契约、判断边界和提纲功能；哪些相关质量门通过，是否出现合理改道或无意漂移，必要时返回哪一层。

中间判断、对外摘要和用户决定分别处理：内部完成必要检查；摘要只公开有审计价值的决定、依据和变化；用户需要参与的取舍则提供具体候选观点、提纲或段落及差异，不以空泛提问替代准备。不倾倒完整内部清单。局部标题、改句或排版任务只建立与当前范围有关的最小契约，可以直接交付；静默执行时关闭本 Skill 的额外决策摘要，相应检查照常完成。

### 写前说明与复核

完整文章创作及实质性重构，在非静默模式下须在全面成文前给出一则简短的写前决定：采用什么核心认识、依据是什么、正文按什么顺序展开。可以先用一句交代主张与关键依据，再用一句交代实际内容的先后安排；不能仅承诺整理主线或调整结构。已有可靠方案时简述沿用的主张与骨架，不重建过程；有重大分歧或缺口时交代影响和待定事项。只做立意或提纲时，以相应产物结束；局部任务不强制增加写前说明。

| 需要说明的决定 | 对外保留的内容 | 内部仍须核对 |
| --- | --- | --- |
| 写前选择 | 核心认识、决定性材料与实际展开顺序；只说明会改变写法的读者或边界要求 | 任务与作者位置、判断依据、立意各维度、主要部分功能和关系 |
| 实质改道 | 新证据与上一版的真实差异、将调整的段落或结构；继续依赖新判断前说明 | 区分原稿主张、自身上一版与新增结论，不虚构撤回；检查是否影响锁定内容、其他论据或授权范围 |
| 复核例外或用户要求的验收 | 具体修正、仍未解决的重要限制，或可核查的检查结果 | 所有适用质量门；没有新信息时不额外发送通过消息 |

#### 立意说明

写前摘要用一句核心认识和关键依据交代立意。以下维度在内部逐项核对，对外只说明影响本次选择的部分；用户明确要求详细立意分析时再展开，不默认给五项检查报告：

- **高度**：联系了什么更大的目标、系统或时间尺度，它怎样改善当前理解；无需扩大尺度时保留当前范围。
- **深度**：解释了哪层机制、矛盾或原因，解释到哪里，是否还有缺口。
- **现实**：具体依据是什么，材料可以支持到哪里，重要事实、反例或边界是否待核。
- **任务**：此次文本要完成什么，选择这个立意如何帮助完成。
- **读者**：读者已有认识和主要困惑是什么，文章怎样帮助其理解；未知时注明假设。

解释或叙事文本按核心问题、变化或体验主线说明，不强迫形成论说文式立意；高度和深度是检查角度，不是每篇都必须最大化的指标。

#### 提纲与结构说明

默认说明实际标题或段落展开顺序、关键部分承担的功能与连接理由，让用户看得出正文将怎样形成。材料落点、局部结构和表达方式仍需内部核对；复杂长文或用户要求详细提纲时，再展开各部分的子判断、论据、主要表达方式及转换关系。已有共识只说明沿用的骨架与改动处，不逐一汇报每处修辞，也不为未使用的方法填空。

#### 成稿复核说明

内部检查立意与任务是否兑现、内容与结构是否连贯、表达与作者特征是否成立，以及适用的事实、反 AI 味和 Markdown 要求。发现会影响读者判断的修正或剩余限制，或用户要求验收说明时，再给出具体落点，例如收窄第三节的因果结论、删除无法核实的引语。没有实质例外时不额外追加检查报告；重要边界仍须进入最终成品，不能只留在过程消息中。

试写、重大改道或方法带来重要增量时，补一则简短说明：试写解决了什么不确定性；哪条新证据改变了什么判断；某项方法使哪处内容发生了什么变化。常规局部动作不逐一汇报，内部候选、无效探索和逐字思维过程不公开。写前说明不能替代最终成品，最终成品也必须与这些说明相互校验。

## 写作能力与方法

以下标题是方法的阅读入口，不是互斥分类或固定步骤。材料可以改变观点，构思可以提出新的论点与论据需求，提纲和试写可以暴露结构问题。A—D 根据当前缺口调用相应方法。

| 概念 | 在本文中的含义 | 与其他概念的关系 |
| --- | --- | --- |
| 主题、观点与材料 | 主题界定讨论对象；观点给出认识或判断；材料提供事实基础，成为论据时需要说明支持关系 | 论点与论据通过论证相连，材料也可以修正论点 |
| 构思 | 思考如何形成观点、选择与解释材料、安排展开，并让读者想清楚的过程 | 横跨内容形成与组织；产生并修正提纲、结构和表达方案 |
| 提纲 | 把构思外化为可检查的层级与排布方案，明确总论点、子论点或各部分职责及材料落点 | 标题是可见骨架，功能、证据与关系说明使其可以展开成正文 |
| 结构形态 | 内容在全文、章节和段落各尺度上的组织方式，如纵向、横向和交叉 | 既体现在大提纲，也体现在子论点内部；整体与局部可以采用不同形态 |
| 逻辑关系 | 内容为什么相连、怎样支持或限制彼此，包括并列、递进、因果和约束等 | 贯穿观点、论据、提纲和结构；需在各尺度检查，不归某一阶段独占 |

提纲中的 A → B → C → S 适用于有真实依赖的推导；每个箭头都要有成立依据。若 A、B、C 分别支持 S，应呈现汇合支持关系，不伪装成逐步推导。逻辑依赖与呈现顺序也要区分：文章可以先说 S 再解释依据，但不能因此省去必要的论证。

### 主题、观点与材料

本组方法处理写什么、形成什么观点、由什么材料支撑。用于论证时，要同时处理论点、论据和论证：材料为何相关、怎样支持判断、能支持到哪里；材料清单本身不能替代论证。

#### 立意能力

本节详述判断型文本的立意方法；解释、叙事与记录文本按 B 阶段的组织中心要求使用相应部分。立意是文章要帮助目标读者形成的核心认识。主题说明写什么，立意必须进一步说明：当前最重要的问题是什么，哪种关系在起作用，作者作出什么判断，这个判断在什么条件下成立或导向什么行动。

可工作的立意通常包含：

> **对象与问题 + 关键关系 + 作者判断 + 成立条件或行动含义**

立意同时接受三种约束：

- **现实约束**：来自真实问题，结论强度不高于证据强度；
- **任务约束**：能够完成本次文本的记录、解释、论证、决策、部署、复盘或传播动作；
- **读者约束**：跨过目标读者真正的认知障碍，不因迎合而改写事实。

同一批材料通常能产生多个候选立意。比较时检查：哪个矛盾最影响结果，哪个判断最有证据，哪个发现给读者带来真实增量，哪个结论由当前作者说最可信。立意不追求最大，要能统领必要材料，又不同时捆绑多篇文章。

所谓**高度**，来自把局部问题放回更大的目标、约束、时间尺度和后果；所谓**深度**，来自穿过现象找到真正影响结果的关系和机制。二者都必须提高判断精度，不能靠宏大词汇获得。

立意必须通过四项检验：

- 能否用一句话给出核心认识，而不只报主题或态度；
- 主要材料是否都在支撑、解释、限制或应用这句话；
- 最强反方会攻击事实、推理、价值标准还是适用条件，作者是否已经回应；
- 读者接受这句话后，认识、判断或行动会发生什么变化。

标题是立意的压缩接口：大标题让读者看见对象、方向和真实价值，小标题把核心判断展开成可理解的部分，并准确呈现并列、递进等真实关系。先让立意与正文成立，再精炼标题；不能为了悬念、对仗或传播承诺迫使材料服从形式。

#### 现实取样、材料和证据能力

写作输入来自观察、工作记录、访谈、数据、文件、阅读、既有笔记和亲身经历。不同来源既增加信息，也带有位置偏差。先区分：

- 已核实事实；
- 来源主张；
- 作者解释；
- 评价标准；
- 尚待验证的推断。

“没有内容可写”时，不用更多套话补满。先检查是否接触真实对象、是否听到不同位置、是否掌握会改变判断的事实。需要研究同类文本时，分别提取其**格式价值、结构价值、内容价值和文风价值**；比较多个样本，避免把单篇习惯误认成文体规律。

材料必须经过转换才能支撑判断：

> **原始信息 → 来源核验 → 事实确认 → 相关性筛选 → 代表性判断 → 解释与比较 → 支撑结论**

关键论证使用：

> **主张 → 证据 → 推理 → 边界**

- **主张**给出需要检验的判断；
- **证据**提供与当前判断相关且可核实的依据；
- **推理**说明证据为何能够支持主张；
- **边界**说明结论依赖的条件、未知和不能外推之处。

数据要交代口径、基线、时间、分母和归因范围；案例适合展示过程与机制，需要说明代表性和可比条件；引语提供概念或立场，权威身份不能代替当前证据；亲身经历要区分观察、记忆、感受和动机推测；规则与文件要核对版本和适用对象；反例用于发现边界或改写机制。

选材时逐项判断：它支持哪个主张，能支持到什么程度，是否存在反例或替代解释，多个材料是否重复，删除后会损失论证还是只减少篇幅。

### 构思与提纲

#### 构思与展开路径

构思贯穿观点形成、论据选择和叙述展开：既思考要形成什么认识及其依据，也思考从哪里进入、沿什么路径让读者理解。这里着重展开切口与路径；观点和材料的方法见“主题、观点与材料”。已有认识可以在构思、提纲和试写中被修正。先找到读者当前最难跨过的障碍，再选择切口、展开路径和结构形态。

有效切口必须同时满足：

- **足够具体**：能落到可观察、可核验的人物、行为、数据、冲突、对象或工作环节；
- **能够展开**：小入口背后连接更大的关系、机制和系统，而非孤立趣闻；
- **具有解释力**：沿着它继续追问，能够解释为什么发生、影响什么和如何处理。

切口缩小的是进入复杂问题的入口，不一定缩小问题本身。一次会议失效可以继续追到议题、信息、责任和决策权；若只停留在会议细节，切口就没有完成向整体机制的展开。

常用主路径包括：

- **问题路径**：表现 → 原因 → 方案 → 保障；
- **认识路径**：现象 → 本质 → 影响 → 边界；
- **行动路径**：目标 → 条件 → 步骤 → 责任 → 反馈；
- **对象路径**：位置 → 信息 → 利益 → 互动 → 结果；
- **时间路径**：起点 → 演化 → 转折 → 现状 → 风险；
- **比较路径**：统一口径 → 差异 → 原因 → 取舍。

路径没有固定优劣。可以局部交叉，但必须有一条主路径；每次切换都要有必要理由和清楚接口，不能把复杂性转嫁给读者。

构思完成后，应能用几句话说清：从哪里进入，为什么从这里进入，读者依次要解决哪些问题，正文采用什么结构，最终如何回到核心认识。

#### 提纲编制

提纲是构思的外化，也是对内容关系的可检验假设。它以标题层级和部分排布呈现文章骨架，同时承载重点内容、结构框架、切入点、着重点和材料落点。论证文章要说明总论点与子论点如何相连；解释或叙事文本可以用问题、过程或情节职责组织。标题清单之外，按任务需要补充必要的证据与功能说明。

下文“关系检查”的四个检查面回答“在哪里检查”，四种关系回答“内容为什么相连”，不能相互替代。关系存在于提纲、材料、论证和正文表达中；并列、递进、因果和约束是常用关系，不能强制把反馈、转折或其他真实关系塞入四类。短文可以简查，复杂长文的详细提纲给每个主要部分标注：

- 承担什么功能；
- 形成哪个子判断；
- 使用什么证据；
- 主要采用叙述、说明还是议论；
- 与上级、同层、前后部分是什么关系。

标注后仍无法说明关系，就必须移动、合并、删除或补充内容。粗提纲先确定主问题、主路径和结构形态，详细提纲再配置判断、材料、过渡和结论；标题措辞可以等正文稳定后精炼。

### 结构与关系

结构与关系贯穿全文、章节、段落和句子，服务于内容展开与所有表达方式。除了论点如何成立，还要检查事件如何衔接、对象如何解释、视角如何切换、语句如何承接，以及节奏与照应怎样服务全文。C 用它检查方案，D 必须对实际正文再检查一次。

#### 结构形态

结构形态同时用于全文、章节、段落与句子；子论点是其中一种组织单元。例如全文可以由三个并列子论点支撑中心观点，每个子论点内部再沿事实、机制和判断纵向展开。叙事可在全文安排事件变化，在局部安排场景、动作与视角；说明可在全文组织整体与部分，在段落内安排定义与实例。检查时分别看整体如何组织、各部分内部如何展开，以及局部怎样回到上一级任务。

结构形态包括：

- **纵向结构**：沿时间、因果、认识深化或行动阶段推进，后文依赖前文并形成新增认识；
- **横向结构**：围绕同一个问题或分类轴展开同层模块，各部分功能和颗粒度一致；
- **交叉结构**：以一条纵向主线推进，在关键节点横向展开，展开后重新回到主线。

展开路径回答“读者依次解决什么问题”，结构形态回答“这些问题怎样排列”。两者都必须服从核心认识，不能把多个现成骨架拼在一起假装复杂。

#### 关系检查

按全文、章节、段落与句子的实际组织检查四个位置；“上级”可以是判断，也可以是主题、场景或表达任务，“下级”需要完成相应功能。同层同轴与 MECE 用于分类，叙事中的人物、动作和环境可以因共同场景相连，不强迫所有材料彼此同类：

| 检查面 | 必须回答的问题 | 未通过的表现 |
| --- | --- | --- |
| 上下 | 下级是否解释、证明、限制或落实上级判断，或完成所属主题、场景与表达任务 | 上级讲原因，下级突然列措施；下级无法归入上级 |
| 同层 | 并列项是否同一分类轴、同一层级和相近颗粒度 | 目标、原因、措施、人物和案例混在一张清单 |
| 前后 | 后文是否由前文推出、回应、转折或形成新增认识 | 标题看似递进，正文换词重复；结论中间缺桥梁 |
| 整体 | 所有部分是否共同完成核心任务 | 局部都正确，合起来没有中心结论或读者路径 |

再标明内容之间属于哪种关系：

- **并列**：同层各项共同构成整体，口径和颗粒度一致；
- **递进**：后文依赖前文并增加信息，不是同一判断换词重说；
- **因果**：说明结果由什么机制产生，同时检查条件、替代原因和反向因果；
- **约束**：说明原则、资源、风险或条件怎样限制其他判断和方案的适用范围。

结构与关系还需按表达方式检查：

| 表达场景 | 需要检查的关系 | 典型故障 |
| --- | --- | --- |
| 叙述 | 时间、空间、视角、动作、伏笔与回应 | 无提示地跳时空或换视角，把先后当因果 |
| 说明 | 定义与实例、整体与部分、现象与机制、已知与新知 | 必要概念未交代，局部说明失去所属对象 |
| 议论 | 主张与依据、推导与条件、反方与回应 | 推理缺桥、边界遗漏，反方没有被回应 |
| 混合表达 | 故事转解释、解释转判断的理由与衔接 | 案例讲完突然升华，表达切换没有承接 |
| 句子与段落衔接 | 指代、信息重心、承接、转折、节奏与照应 | “这”无所指、连接词虚接、反复铺垫而无推进 |

关系检查要落实到实际文本：指出缺失的承接、重复的作用或不成立的联系，再按影响范围调整。节奏、情绪、场景和审美作用可以成立，不要求每句话都推导新论点。

### 贯穿写作的思维方法

括号内阶段表示常见使用位置，不限定适用范围；实际按缺口调用，也可用于形成新认识和表达方案。先识别当前具体问题，再选择能改变内容的方法，并核对实际变化。没有增量就停止或更换方法，不为使用名称而继续展开。

| 当前问题 | 可选方法与动作 | 可检查的结果 |
| --- | --- | --- |
| 一个案例承担了过强结论 | 实证：核代表性、补来源或收窄主张 | 增加具体依据或明确适用条件 |
| 局部都正确，全文却没有共同任务 | 系统：检查局部与整体、对象与环境 | 调整部分职责，补出关键联系 |
| 前后跳跃、概念混用或因果不明 | 逻辑：核概念、前提、关系与推导 | 修复具体衔接或撤回越界判断 |
| 忽略读者疑问或最强反方 | 多视角：从相关位置提出真实质疑 | 增加回应、代价或失效条件 |
| 抽象机制难懂或常规角度无解释力 | 形象与创新：试用场景、类比或新连接 | 更易理解的表达；说明类比边界 |

这些是调用例子，不是封闭分类。方法贡献可以直接体现在正文；只有贡献重要或用户要复用方法时，才在决策说明中简述它改变了什么。

- **实证思维（A、B、D）**：区分事实、解释、评价和建议；核来源、找替代原因、说明评价标准和建议代价。
- **系统思维（B、C）**：把文章看成围绕一个核心任务运行的整体，检查局部与整体、短期与长期、对象与环境的关系。
- **逻辑思维（B、C、D）**：检查概念口径、内容关系、分类轴、因果机制、推理有效性和行动对应。
- **多视角思维（B、D）**：从不同位置、时间尺度和最强反方检验判断，用于发现边界与遗漏，不平均拼接所有意见。
- **形象与创新思维（C、D）**：用场景、比喻和新连接降低理解成本或提出新解释；形象不能替代证据，创新不能越过事实、文体和授权。

### 叙述、说明与议论

先判断读者缺少什么，再选择主要表达方式：读者看不见事实怎样发生，用叙述；读者不理解对象是什么、由什么构成或如何运行，用说明；读者无法判断应当相信什么、选择什么及其理由，用议论。

#### 叙述：让事实过程可见

叙述选择与判断有关的人物、环境、动作、变化、转折和结果，回答“发生了什么、怎样发生”。它可以让抽象问题落到可观察过程，也可以展示机制如何实际运行。

叙述必须忠于材料。不能为了戏剧性补造心理、对白、情绪和细节，也不能用时间顺序暗示未经证明的因果。故事提供可感知性，仍需说明它为何相关、是否具有代表性、能够证明到哪里。

#### 说明：把对象、差异和机制讲清楚

说明回答“它是什么、由什么构成、怎样运行、与什么不同”。可按任务调用定义、分类、比较、流程、数据、图表、举例和机制拆解。

说明必须给出清楚口径、关键关系和必要限制。分类只是降低理解成本，不能自动解释原因；流程展示先后，不能自动证明因果；数据展示差异，仍需解释基线、口径和机制。

#### 议论：完成判断和取舍

议论回答“应当怎样理解或选择，以及为什么”。稳定单元包括主张、证据、推理、反方和边界，可以使用归纳、演绎、类比、因果分析和例证。

归纳要防止把有限样本无限外推；演绎要检查前提；类比要确认关键结构相似；因果分析要排除共同原因、反向因果和时间巧合。态度、引用数量和论据相关性都不能单独完成论证。

三种方式可以在一段或一节中组合，但每个段落要有主要作用。先检查：“这一段让读者多看见了什么、理解了什么，或完成了哪一步判断？”若其作用是场景、情绪、节奏、视角或照应，再检查它如何服务全文。两类检查均无法说明贡献时，删除、合并或重写。表达方式切换还应通过 [结构与关系](#结构与关系) 检查。

## 交付边界

- **笔记、纪要与知识框架**：先进入本模块确定文本用途，再完整读取笔记 reference；记录型产物优先保全与溯源，面向读者的主笔记和专题笔记同时接受共同结构、语言、反 AI 味与 Markdown 约束。
- **选题诊断**：给判断、可行切口和决定成败的材料缺口，不直接扩写全文。
- **立意或提纲**：交付核心认识、认知路径、结构形态、功能型提纲、证据缺口和未通过的关系检查。
- **完整成稿**：从输入成熟位置完成 A—D 的相关质量门，最终只交付可读文本。
- **改写或协作修改**：保护用户要求保留的事实、判断、作者位置和边界，修到真正故障层；用户未要求说明时不附修改课。
- **质检**：指出未通过的质量门、证据和返工入口；用户未要求改写时不擅自重写。
- **标题、摘要或排版**：只进入对应局部阶段，不重跑完整流程。
- **写作训练与复盘**：围绕一次真实产出给出可修正反馈、对照修改和下一次验证任务，不用泛泛的“多读多写”代替训练闭环。
