# Workspace maintenance operations

Choose only the operation needed by the task. Existing canonical documents and the user's requested output take precedence over these defaults.

## Bootstrap or reorganize

Identify canonical notes, raw sources, code, outputs, and scratch files. Repair the smallest missing navigation or placement rule. Create AGENTS.md, a wiki index, or a log only when that workspace needs one; keep existing meaningful files in place unless the task authorizes and benefits from moving them.

## Domain build or supplement

For an initial domain knowledge base, clarify the question and application boundary, then connect source evidence, source-level notes, and a cross-source main framework. For a supplement, read the relevant main-note section and source index, classify the contribution, and integrate it. A source can be indexed directly when a standalone second-layer note would add no continuing value.

Use [vertical-knowledge-base.md](vertical-knowledge-base.md) for substantive domain compilation. Test whether incoming material reinforces, refines, extends, contradicts, or reclassifies the framework; it may remain an open question instead of becoming a firm conclusion.

## Ingest

Verify the incoming source, its identity and coverage. Update the appropriate source note or existing provenance index, integrate durable contributions into their main home, and change navigation only when necessary. Keep sources and judgments distinguishable.

## Query

Locate the minimum relevant page directly or through the index. Answer with source support and inspect originals when needed. Querying alone does not require persistent writeback.

## Promote

When durable maintenance is authorized, integrate the result into an existing page; create a new page only for a distinct, useful role. Update affected links and the existing concise maintenance log.

## Lint

Check broken links, stale claims, weak provenance, orphaned pages, and repeated concepts in the requested scope. Resolve the main home and reference route; verify moves with a recoverable mapping. Stop when the requested content and navigation are sound.
